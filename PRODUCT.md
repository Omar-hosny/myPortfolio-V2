# Product

## Register

brand

## Users

Employers, recruiters, and hiring managers evaluating Omar Hosny for front-end developer roles — primarily remote-first companies and international tech teams. Visitors land here with a quick decision to make: "Should I interview this person?" The site must answer that in seconds.

## Product Purpose

Convince hiring managers to reach out for interviews. The portfolio is Omar Hosny's most important UI — the one where the developer IS the product. Every section earns its place by answering: "Why hire this person?"

## Brand Personality

Bold / Technical / Cutting-edge. Confident but not arrogant — the code speaks for itself. Developer-native but not alienating to non-technical hiring managers. Think: clean typographic system with moments of technical flair that demonstrate craft.

## Anti-references

- Generic SaaS / startup templates — anything that looks like a landing page for a B2B tool
- Over-designed / flashy portfolios — excessive animations, loud effects, style over substance
- Outdated developer portfolio clichés — the 2010s dev-portfolio tropes (gradient heroes, floating avatar, terminal gimmicks)
- AI-generated-looking patterns — the "made by GPT" tells (gradient text, ghost cards with shadows, ultra-rounded corners, glassmorphism as default, numbered section markers, tiny uppercase eyebrow labels on every section)

## Design Principles

1. **The work proves the point.** Every design decision should demonstrate the frontend skill it claims. Clean architecture, semantic HTML, accessible by default, performant.

2. **Bold confidence, earned detail.** Big typography and strong hierarchy first; decorative elements only where they reinforce the narrative.

3. **One page, one story.** Linear narrative flow — introduction → proof → expertise → track record → action. No digressions.

4. **Human before developer.** The portfolio sells the person, not just the tech stack. Warmth in copy, personality in craft.

5. **Distinctive on purpose.** If someone could say "AI made this portfolio," the design has failed. Own the aesthetic; reject the default.

## Accessibility & Inclusion

WCAG 2.2 AA. Full keyboard navigation, skip-to-content, sufficient contrast ratios, reduced-motion support, semantic structure, touch targets ≥ 24px.
